# Product Overview

Mobile Scaffolding: a reference Android project (Unlam, Mobile Technology course) that shows how to organize an app using hexagonal architecture with Jetpack Compose. Currently a skeleton with a stub `Book` domain.

## Core Capabilities

- Reference package layout (domain / data / ui) for course projects
- Hexagonal separation: business logic independent of UI and persistence
- CI quality gates on every PR (ktlint + Android lint, unit tests with Kover coverage)

## Target Use Cases

- Students bootstrapping an Android app from a consistent base
- Teaching ports/adapters, container/component UI, and Hilt DI

## Value Proposition

- Opinionated, minimal starting point: architecture and tooling are pre-wired, features are added on top
- README (Spanish) is the pedagogical reference; source layout is the source of truth where they differ
